# סוכן טיוטות תשובה למייל

סוכן ל-Claude Code שמאתר מיילים שלא נענו, מנסח טיוטות בסגנון של אמיר, ומבקש אישור על כל אחת לפני שליחה.

## מבנה
| קובץ | תפקיד |
|---|---|
| `.claude/skills/email-reply-drafter/SKILL.md` | התהליך המלא (איתור → סגנון → טיוטות → אישור → למידה) |
| `.claude/settings.json` | הרשאות: קריאה/טיוטות/לייבלים מותרים, `reply` דורש אישור, שליחה/העברה/מחיקה חסומות |
| `CLAUDE.md` | כללי הבטיחות הקבועים |
| `style-guide.md` | נוצר אוטומטית בריצה הראשונה ומתעדכן מהעריכות שלך |

## הפעלה
1. ודא ש-Gmail מחובר כ-connector ב-claude.ai (Settings → Connectors).
2. מתוך התיקייה הזו:
   ```bash
   cd email-agent
   claude
   ```
3. כתוב: `תריץ את סוכן המיילים` (או `/email-reply-drafter`).

## שכבות הגנה
- `send_message`, `forward`, מחיקה וספאם - חסומים לגמרי ב-`deny`.
- `reply` ב-`ask` - Claude Code יבקש אישור לפני כל שליחה, בנוסף לאישור בשיחה.
- ההרשאות מוגדרות גם לשם `mcp__claude_ai_Gmail__*` (CLI מקומי) וגם ל-`mcp__Gmail__*` (סשן ענן).
