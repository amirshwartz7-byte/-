# סוכן אסטרטגיה ואופרציה עסקית

סוכן ל-Claude Code שחושב כמו מנהל אופרציה עסקית בכיר: מקבל משימה, חוקר אותה באינטרנט,
מנתח במספרים ובראייה מערכתית, בונה תהליך עבודה שמחזיק סקייל - ומגיש **מסמך פתרון** ו**מצגת פשוטה**.

## מה הוא עושה
| שלב | מה קורה |
|---|---|
| 1. הבנה | מנסח את היעד, מזהה מידע חסר, שואל עד 3 שאלות או רושם הנחות |
| 2. מסגור | North Star Metric ועץ מדדים (מה בפועל מזיז את המספר) |
| 3. מחקר | 2-4 סוכני מחקר במקביל: benchmarks, case studies, כלים, הקשר מקומי |
| 4. אבחון | מפת תהליך, צוואר בקבוק, שורש הבעיה, שווי הפער בכסף |
| 5. פתרון | חלופות + המלצה, תהליך חדש עם בעלים ו-SLA, RACI, סקייל פי 10, ROI, מדדים, 30-60-90, סיכונים |
| 6-7. מסירה | `solution.md` + `presentation.html` |
| 8. בקרה | צ'קליסט איכות לפני מסירה |

## מבנה
| קובץ | תפקיד |
|---|---|
| `.claude/skills/ops-strategist/SKILL.md` | התהליך המלא של הסוכן |
| `.claude/agents/ops-researcher.md` | סוכן משנה למחקר רשת (מחזיר ממצאים עם קישורים) |
| `templates/solution-template.md` | מבנה מסמך הפתרון |
| `templates/slides-template.md` | מבנה המצגת + הסבר התחביר (כרטיסי KPI, תרשים שלבים) |
| `scripts/build_deck.py` | ממיר `slides.md` למצגת HTML עצמאית (בלי תלויות) |
| `outputs/` | כאן נשמרים הפתרונות, תיקייה לכל משימה |
| `.claude/settings.json` | הרשאות: חיפוש וקריאה ברשת, כתיבה רק ל-`outputs/` |

## הפעלה
```bash
cd ops-agent
claude
```
ואז פשוט כתוב את המשימה, למשל:
> אנחנו מקבלים 400 פניות שירות בשבוע, זמן תגובה ממוצע 9 שעות ו-3 נציגים. אני רוצה להכפיל את מספר הלקוחות בלי להכפיל את הצוות.

או במפורש: `/ops-strategist <המשימה>`

## הפלט
```
outputs/2026-10-03-support-scale/
├── solution.md        # מסמך הפתרון המלא
├── slides.md          # מקור המצגת (אפשר לערוך ולבנות מחדש)
└── presentation.html  # המצגת - פותחים בדפדפן
```
- **ניווט במצגת:** חיצים / רווח / החלקה בנייד. `Ctrl+P` → "שמור כ-PDF" לייצוא.
- **עריכה:** משנים את `slides.md` ומריצים `python3 scripts/build_deck.py outputs/<folder>/slides.md`.
- **פורמטים נוספים:** אפשר לבקש מהסוכן לייצא ל-Word, PowerPoint או Google Docs/Slides.

## עקרונות
- כל מספר מסומן כמקור / הנחה / חישוב - אין נתונים ממציאים.
- המלצה אחת ברורה, לא רק סקירת אפשרויות.
- כל שלב בתהליך: בעלים, SLA, ומה מאוטמט.
- פשוט וממוקד: עובד חדש בצוות מבין בקריאה אחת.
