# סוכן איתור סטארטאפים אחרי סיד

סוכן ל-Claude Code שמאתר סטארטאפים שגייסו סבב סיד לאחרונה, מזהה את המנכ"ל, מאתר את כתובת המייל שלו
ומכין ב-Gmail טיוטת פנייה שבה אמיר מציע את עצמו כמוביל אופרציה עסקית. בסוף כל ריצה נשלח סיכום בוואטסאפ.
**הסוכן לא שולח מיילים.** הטיוטות מחכות ב-Gmail לאישור ולשליחה ידנית.

## מבנה
| קובץ | תפקיד |
|---|---|
| `.claude/skills/startup-outreach/SKILL.md` | התהליך המלא: איתור, מנכ"ל, מייל, טיוטה, תיעוד, וואטסאפ |
| `profile.md` | **למלא לפני הריצה הראשונה:** הרקע, ההישגים והקריטריונים של אמיר |
| `leads.csv` | יומן כל החברות שנבדקו, כדי שלא יהיו פניות כפולות |
| `scripts/send-whatsapp.sh` | שליחת סיכום לוואטסאפ דרך CallMeBot |
| `scripts/find-email.sh` | איתור מייל דרך Hunter.io (אופציונלי) |
| `.claude/settings.json` | הרשאות: חיפוש ויצירת טיוטות מותרים. שליחה, תשובה, העברה ומחיקה חסומות |

## הגדרה
1. למלא את `profile.md`.
2. Gmail מחובר כ-connector ב-claude.ai (Settings → Connectors).
3. משתני סביבה (בענן: בהגדרות הסביבה, לא בקוד):
   - `CALLMEBOT_PHONE`: המספר שלך בפורמט בינלאומי, למשל `972501234567`
   - `CALLMEBOT_APIKEY`: המפתח שקיבלת מ-CallMeBot
   - `HUNTER_API_KEY`: אופציונלי, משפר את דיוק המיילים
4. בענן: להוסיף ל-Allowed domains ברשת את `api.callmebot.com` (וגם `api.hunter.io` אם משתמשים בו).

## הפעלה
```bash
cd startup-outreach-agent
claude
```
ולכתוב: `תריץ את סוכן הסטארטאפים` (או `/startup-outreach`).
לריצה אוטומטית אפשר להגדיר Routine מתוזמן, למשל בימים א'-ה' ב-08:00.

## מגבלות
- אין התחברות ללינקדאין ואין גירוד שלו (זה נוגד את תנאי השימוש ומסכן את החשבון). הסוכן משתמש בחיפוש רשת ציבורי.
- כתובת שמסומנת `ניחוש` לא אומתה. הטיוטה תכלול שורת אזהרה שצריך למחוק לפני שליחה.
