# סוכן איתור סטארטאפים אחרי סיד

סוכן ל-Claude Code שעושה שני דברים בכל ריצה:
1. **טיוטות פנייה:** מאתר סטארטאפים שגייסו סבב סיד לאחרונה, מזהה את המנכ"ל, מאתר את כתובת המייל שלו,
   ומכין ב-Gmail טיוטה שבה עמיר מציע את עצמו כמוביל אופרציה עסקית.
2. **תקציר לפגישה:** אם עמיר שלח פנייה והחברה ענתה, הסוכן שולח לעמיר (ורק אליו) מייל עם תקציר
   על החברה והמנכ"ל, נקודות חיבור ושאלות לפגישה.

עמיר מחליט על כל פנייה: שולח את הטיוטה מ-Gmail כדי לאשר, או מוחק אותה כדי לסרב.

## מבנה
| קובץ | תפקיד |
|---|---|
| `.claude/skills/startup-outreach/SKILL.md` | התהליך המלא |
| `profile.md` | הרקע, ההישגים, הקריטריונים והסגנון של עמיר (מקורות החיים ומהלינקדאין) |
| `scripts/find-email.sh` | איתור מייל דרך Hunter.io (אופציונלי) |
| `.claude/settings.json` | הרשאות. שליחה מותרת רק בשביל מייל התקציר לעמיר, לפי הכללים ב-`CLAUDE.md`. תשובה, העברה ומחיקה חסומות |

## איפה נשמר המצב
הריפו ציבורי, ולכן פרטי הלידים לא נשמרים בו:
- **Google Drive → `Startup Outreach Log`:** קובץ לכל חברה שנבדקה. משמש למניעת פניות כפולות.
- **לייבלים ב-Gmail:** `סטארטאפים/פנייה` ו-`סטארטאפים/תקציר-נשלח`.

## הפעלה
```bash
cd startup-outreach-agent
claude
```
ולכתוב: `תריץ את סוכן הסטארטאפים` (או `/startup-outreach`).
אפשר גם להגדיר Routine מתוזמן, למשל בימים א'-ה' ב-08:00.

## מגבלות
- אין התחברות ללינקדאין ואין גירוד שלו. הסוכן משתמש בחיפוש רשת ציבורי.
- כתובת שמסומנת `ניחוש` לא אומתה. הטיוטה תכלול שורת אזהרה שצריך למחוק לפני שליחה.
- הטיוטות נוצרות בלי קובץ מצורף. כדאי לצרף קורות חיים ב-Gmail לפני שליחה.
