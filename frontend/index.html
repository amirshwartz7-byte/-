אירועים מומלצים למעקב

מה אמיתי כאן ומה עדיין דורש חשבונות חיצוניים: זהו backend אמיתי (Flask + SQLite) שרץ מקומית — הנתונים נשמרים בפועל בין רענוני דף (בדוק: הוסף חברה, רענן את העמוד, היא עדיין שם). מה שעדיין דורש חיבור אמיתי לשירותים חיצוניים: (1) Google OAuth אמיתי במקום כפתור ה-Demo — דורש חשבון Google Cloud מאומת (ראו PRD סעיף 9.2), (2) מאגר חברות חי במקום 5 הדוגמאות — דורש מפתח API בתשלום (Harmonic/Crunchbase/Apollo).
זהו ה-MVP הריצתי בפועל של מצפן, לפי מסמך ה-PRD — Flask backend + SQLite, ממשק שמדבר עם REST API אמיתי. קוד המקור המלא נמצא בתיקייה שקיבלת יחד עם קובץ זה.
