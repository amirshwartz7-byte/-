# Done — מערכת לניהול תהליך מעבר דירה

אפליקציית ווב (React + TypeScript + Vite + Tailwind) לניהול מעבר דירה מא' ועד ת': Onboarding מהיר, צ'ק-ליסט חכם המבוסס על תאריך המעבר, מרקטפלייס ספקים עם מנגנון לידים, בונה חבילת שירותים, מחשבון תקציב עם עדכון אוטומטי, ספרייה של ספרים/מדריכים מומלצים, וממשק ניהול (Admin) לניהול משתמשים, ספקים, לידים ותוכן.

## הרצה מקומית

```bash
npm install
npm run dev
```

כניסת מנהל מערכת זמינה מקישור בתחתית מסך ההתחברות, או ישירות בנתיב `#/admin`.

## בנייה לפרודקשן

```bash
npm run build
```

## ארכיטקטורה

- **ניתוב:** `react-router-dom` (HashRouter)
- **מצב אפליקציה:** React Context + `localStorage` (`src/store/AppContext.tsx`)
- **דאטה לדוגמה:** `src/data` (תבניות משימות, ספקים, ספרים, ערים, משתמשי דמו לאדמין)
- **מסכי משתמש:** `src/pages`
- **ממשק ניהול:** `src/pages/admin`
